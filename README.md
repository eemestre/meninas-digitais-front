Passo a passo para rodar o front:

1. Baixar node.js: https://nodejs.org/en/download
    - configurações: node=24.22.0 / using nvm / (seu os) / with npm

2. clonar repositório: https://github.com/eemestre/meninas-digitais-front
3. na pasta do repositório:
    - npm install
    - npm run dev
    - abrir localhost:3000 no navegador
